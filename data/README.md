# Data and Evaluation for Arabic AI

High-performing models depend on high-quality data. This section tracks the most important corpora, benchmarks, and leaderboards that drive Arabic AI research forward.

## 📚 Key Corpora

| Corpus | Type | Context |
| :--- | :--- | :--- |
| **ArabicWeb16** | Web Crawl | High coverage of Egyptian, Gulf, and Maghrebi dialects. |
| **OSCAR** | Multilingual | Language-classified Common Crawl data. |
| **Common Voice** | Speech | Community-driven audio recordings and transcriptions. |
| **Shami Corpus** | Dialect | Natural conversations for Levantine adaptation. |
| **Darija Open Dataset** | Text/Speech | Moroccan Darija text and audio datasets. |
| **Habibi Dataset** | Speech | High-quality Arabic audio dataset. |

## 🇲🇦 Moroccan Darija Datasets

| Dataset | Type | Size | Description |
| :--- | :--- | :--- | :--- |
| **Darija Open Dataset** | Text | 1M+ tokens | Community-driven Moroccan Darija corpus |
| **Common Voice Darija** | Speech | 100+ hours | Mozilla community recordings |
| **Moroccan News Corpus** | Text | 500K+ articles | News articles in Moroccan Arabic |

## 🏁 Native Benchmarking

Research is shifting from **translated benchmarks** (which suffer from cultural misalignment) to **native benchmarks** created in Arabic.

- **ArabicMMLU**: Native school exams.
- **ArabLegalEval**: Specialized legal knowledge.
- **AraTrust**: Safety and hallucination checks.
- **OALL Leaderboard**: Open Arabic LLM evaluation.
- **Silma TTS Benchmark**: Arabic TTS quality evaluation.

# Tools and Libraries for Arabic NLP

This repository lists specialized tools required for cleaning, segmenting, and evaluating Arabic text.

## 🛠️ Core Libraries

- **[Camel-tools](https://github.com/CAMeL-Lab/camel_tools)**: The most comprehensive toolkit for morphology, NER, and sentiment.
- **[Farasa](https://farasa.qcri.org/)**: Industry standard for high-speed preprocessing in Qatar.
- **[PyArabic](https://github.com/linuxscout/pyarabic)**: Essential for basic text manipulation and diacritic handling.
- **[YouTube Audio Extractor](https://github.com/Oddadmix/youtube-audio-extractor)**: A powerful tool for building Egyptian ASR datasets from YouTube, featuring AI transcription (Gemini 2.0 Flash) and VAD filtering.

## 🇲🇦 Moroccan Arabic (Darija) Tools

- **[Darija Transliterator](https://github.com/moroccan-nlp/darija-transliterator)**: Convert between Arabic script and Latin script (Arabizi) for Moroccan Darija.
- **[Darija Normalizer](https://github.com/moroccan-nlp/darija-normalizer)**: Text normalization specifically for Moroccan Arabic dialect.
- **[Darija Stop Words](https://github.com/moroccan-nlp/darija-stopwords)**: Comprehensive stop words list for Darija text processing.

## 🧪 Evaluation Tools

- **LM Evaluation Harness (Arabic)**: Use this to test your models against native benchmarks like ArabicMMLU.
- **WER/CER Scripts**: Standard scripts for evaluating Speech-to-Text performance.

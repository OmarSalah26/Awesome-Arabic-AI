# Moroccan Arabic (Darija) Resources

This directory contains resources specifically for Moroccan Arabic (Darija) - the dialect spoken in Morocco.

## 🇲🇦 Overview

Moroccan Arabic, commonly known as **Darija**, is a Maghrebi Arabic dialect spoken by over 30 million people. It has unique characteristics that distinguish it from Modern Standard Arabic (MSA) and other Arabic dialects:

- **Heavy borrowing** from French, Spanish, and Berber (Tamazight)
- **Distinct phonology** and pronunciation patterns
- **Code-switching** between Arabic script and Latin script (Arabizi)
- **Limited NLP resources** compared to other dialects

## 🎯 Challenges

Moroccan Darija NLP faces unique challenges:

1. **Lack of standardization**: Multiple ways to write the same word
2. **Code-switching**: Heavy use of French and Arabic in the same sentence
3. **Limited resources**: Fewer datasets compared to MSA and other dialects
4. **Arabizi**: Use of Latin characters with numbers (e.g., "7" for "ح")
